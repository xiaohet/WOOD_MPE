This is the window-based onset/offset detection (WOOD) model for multi-pitch estimation (MPE). 
"WOOD_codes.ipynb" notebook provides the full process of reading the audio dataset, forming the model input, building and training the model, and testing the results.
The notebook is supposed to run on Google Colab.
The Model_Example folder contains a saved WOOD model, which is the latest version of the trained WOOD model. Upload it to the workspace so to skip the training part in the notebook.
Go to https://www.kaggle.com/datasets/xiaohet/exemplar-based-polyphonic-audio-dataset to get the dataset. The dataset is supposed to be uploaded to Google Drive.
